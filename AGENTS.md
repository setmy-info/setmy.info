# setmy.info

This is a maven multimodule monorepo project.

## General development tools

- As it is a huge project, AI agents should analyze, investigate only module source code mentioned in the exact tasklist
- Maven spring boot application and backend module in springboot-start-project
- Grepping for open source and free software is forbidden. Agent should take information from the model only because it
  is described there
- tail and grep are allowed in the project root folder recursively by default and no need to ask permission
